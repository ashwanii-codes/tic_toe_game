# Tic Toe Game 🎮

A simple **Tic Toe Game** built using Python.

## 📌 About the Project

This is a beginner-friendly Python project that allows two players to play a Tic Toe game.

Players take turns placing their symbols on a 3×3 board. The first player to get three symbols in a row wins the game.

## 🎯 Features

* Two-player gameplay
* 3×3 game board
* Win detection
* Draw detection
* Simple command-line interface

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

Clone this repository:

```bash
git clone https://github.com/ashwanii-codes/tic_toe_game.git
```

Open the project folder:

```bash
cd tic_toe_game
```

Run the game:

```bash
python tic_toe_game.py
```

## 🎮 How to Play

1. Run the Python program.
2. Player 1 and Player 2 take turns.
3. Enter the position where you want to place your symbol.
4. Get three symbols in a row to win.
5. If all positions are filled without a winner, the game is a draw.
